
# Laboratory 05: The Cloud Data Engineer

## Mission Overview
As a Cloud Data Engineer at CloudNova Technologies, this laboratory activity focuses on deploying an S3-compatible Object Storage service using MinIO on Docker. The goal is to provide persistent, scalable storage for a client's media assets, resolving the ephemeral storage limitations of containerized application servers.

## Objectives
- Compare Block, File, and Object Storage architectures.
- Deploy an S3-compatible MinIO object storage container via Docker.
- Access containerized services using port forwarding and web-based management consoles.
- Provision storage buckets and manage object lifecycles over a web GUI.
- Document deployment steps using structured Markdown.

## Tools Used
- **Docker Engine & Docker CLI**
- **MinIO Object Storage Server**
- **KillerCoda Playground (Ubuntu / Docker Runtime)**
- **GitHub & Git Version Control**

## Skills Learned
- Object storage architecture management and bucket policy concepts.
- Configuring environment variables in Docker runtime containers (`-e`).
- Mapping multi-port Docker services (`9000` API, `9001` Console).
- Port forwarding and browser-based cloud application administration.
