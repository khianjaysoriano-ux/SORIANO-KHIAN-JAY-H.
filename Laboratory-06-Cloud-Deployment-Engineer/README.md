
# Mission 6: The Cloud Deployment Engineer

## Mission Overview
This laboratory demonstrates how to deploy a multi-tier private cloud storage application using Docker Compose, Nextcloud, and MariaDB.

## Objectives
- Understand two-tier architecture.
- Create a Docker Compose YAML configuration.
- Deploy and manage multiple containers.
- Access the Nextcloud web interface.
- Document Infrastructure as Code (IaC).

## Commands Executed
```bash
mkdir nextcloud-deployment
cd nextcloud-deployment
nano docker-compose.yml
docker-compose up -d
docker-compose ps
docker-compose down
```

## Skills Learned
- Linux command-line operations
- YAML configuration
- Docker Compose
- Container networking
- Multi-tier application deployment
- Markdown documentation and GitHub portfolio management
