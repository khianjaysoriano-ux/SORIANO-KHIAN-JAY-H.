

# Laboratory Activity 02 Reflection

## 1. What was the most important concept you learned in this activity?
The most crucial concept I learned is how individual cloud resources—such as compute instances, storage drives, and network configurations—interconnect inside an isolated Virtual Private Cloud (VPC). Understanding the distinction between raw block storage and scalable object storage, along with how Linux terminal commands extract real-time system specifications, gave me a clearer understanding of cloud server architecture.

---

## 2. How does using Markdown and GitHub improve technical documentation?
Utilizing Markdown together with GitHub provides several distinct advantages:
* **Structured and Clean Presentation:** Markdown allows technical reports to maintain a professional, easily readable format without complex styling tools.
* **Version Control and Tracking:** Using Git ensures that every update, revision, or commit to system documentation is logged and easily traceable over time.
* **Centralized Portfolio Management:** Storing code, architecture diagrams, and system reports in a single GitHub repository makes sharing work with peers and instructors seamless.

---

## 3. How will this knowledge help in building cloud applications in the future?
Grasping the fundamentals of cloud infrastructure (Compute, Storage, and Networking) serves as the core foundation for designing reliable and scalable applications. Furthermore, recognizing how different Cloud Service Providers (AWS, Azure, GCP) map their services makes it significantly easier to migrate systems, manage cloud costs, and apply proper security protocols in future real-world projects.
