
# Cloud Provider Service Comparison

This document compares equivalent core cloud services across the top three Cloud Service Providers (CSPs): Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP).

---

## Comparison Table

| Core Cloud Category | AWS Equivalent | Microsoft Azure Equivalent | GCP Equivalent |
| :--- | :--- | :--- | :--- |
| **Compute (VMs)** | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| **Object Storage** | Amazon S3 | Azure Blob Storage | Cloud Storage |
| **Block Storage** | Amazon EBS | Azure Managed Disks | Compute Engine Persistent Disk |
| **Virtual Networking** | Amazon VPC | Azure Virtual Network (VNet) | VPC Network |
| **Serverless Functions** | AWS Lambda | Azure Functions | Cloud Functions |

---

## Key Observations & Insights

1. **Naming Conventions:** 
   * **AWS** often uses functional or branded acronyms (e.g., EC2, S3, EBS).
   * **Azure** and **GCP** generally use more descriptive titles for their services (e.g., Virtual Machines, Cloud Storage).

2. **Core Capabilities:** 
   * All three providers offer identical primary capabilities: elastic compute scaling, durable object storage, and isolated virtual networks with fine-grained firewalls.

3. **Multi-Cloud Strategy:** 
   * Understanding these equivalent service mappings is critical for architects to avoid vendor lock-in and design seamless multi-cloud or hybrid infrastructure strategies.
