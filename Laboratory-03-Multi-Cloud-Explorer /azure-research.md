
# Microsoft Azure Platform Research

## Brief Overview
Microsoft Azure, launched in 2010, is Microsoft's public cloud computing platform. Azure provides a broad range of cloud services, including compute, analytics, storage, and networking. It is widely known for its seamless integration with existing Microsoft enterprise environments and software ecosystems.

## Global Infrastructure
Azure manages a vast global physical infrastructure:
* **Regions:** Over 60+ declared regions worldwide, offering broader regional presence than many competitors.
* **Availability Zones:** Unique physical locations within an Azure region featuring independent power, cooling, and networking.
* **Geographies:** Bound boundaries containing two or more regions that preserve data residency and compliance limits.

## Cloud Management Console
The Azure Portal is a unified, web-based console that allows administrators to build, manage, and monitor everything from simple web apps to complex cloud applications using dashboards and resource groups.

![Azure Management Console](assets/screenshots/azure-console.png)

## Four Core Services
1. **Azure Virtual Machines (VMs):** On-demand, scalable computing resources for Linux and Windows Server environments.
2. **Azure Blob Storage:** Massively scalable object storage for unstructured data such as text, binary files, and media.
3. **Azure Virtual Network (VNet):** Enables secure communication between Azure resources, the internet, and on-premises networks.
4. **Microsoft Entra ID (formerly Azure Active Directory):** Cloud-based identity and access management service.

## Three Key Advantages
* **Seamless Microsoft Integration:** Unmatched compatibility with Active Directory, Windows Server, SQL Server, and Microsoft 365.
* **Hybrid Cloud Leadership:** Strong hybrid cloud tools like Azure Arc and Azure Stack for seamlessly connecting on-premises infrastructure.
* **Enterprise Licensing Flexibility:** Flexible hybrid benefits for organizations using existing Windows and SQL licenses.

## Typical Enterprise Use Cases
* **Enterprise Hybrid Deployments:** Connecting corporate data centers with public cloud infrastructure.
* **Enterprise Software Migration:** Migrating legacy Windows Server and SQL Server workloads.
* **Identity and Access Governance:** Centralized directory and SSO across corporate applications.
