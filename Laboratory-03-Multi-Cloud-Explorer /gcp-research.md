
# Google Cloud Platform (GCP) Research

## Brief Overview
Google Cloud Platform (GCP), launched in 2008, is a suite of cloud computing services offered by Google. It operates on the same infrastructure that Google uses internally for its end-user products, such as Google Search, Gmail, and YouTube, making it highly recognized for big data, containerization, and artificial intelligence.

## Global Infrastructure
GCP leverages Google's global fiber network:
* **Regions:** Independent geographic areas with multiple zones.
* **Zones:** Deployment areas within a region representing single failure domains.
* **Private Fiber Network:** Utilizes Google’s high-speed global backbone network to minimize latency and packet loss between regions.

## Cloud Management Console
The Google Cloud Console provides an intuitive interface to manage project-based environments, view real-time metrics, access Cloud Shell, and deploy resources.

![GCP Management Console](assets/screenshots/gcp-console.png)

## Four Core Services
1. **Google Compute Engine (GCE):** High-performance, customizable virtual machines running in Google's data centers.
2. **Google Cloud Storage (GCS):** Unified, durable object storage for data archiving, live streaming, and machine learning input.
3. **Google Kubernetes Engine (GKE):** Managed, production-ready environment for deploying containerized applications (the birthplace of Kubernetes).
4. **BigQuery:** Serverless, highly scalable, and cost-effective multi-cloud data warehouse designed for business agility.

## Three Key Advantages
* **Pioneer in Containers & Kubernetes:** Industry leader in containerization tech and managed Kubernetes orchestration.
* **Data Analytics & AI Leadership:** Superior native tools for AI/ML (Vertex AI) and real-time big data processing (BigQuery).
* **Global Network Performance:** Direct routing through Google's private global fiber-optic infrastructure.

## Typical Enterprise Use Cases
* **AI & Machine Learning:** Training complex deep learning models using Tensor Processing Units (TPUs).
* **Real-time Big Data Analytics:** Running petabyte-scale queries in seconds with BigQuery.
* **Modern Microservices Architecture:** Container orchestration using Google Kubernetes Engine.
