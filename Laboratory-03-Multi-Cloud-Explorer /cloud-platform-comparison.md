## Analysis Questions

### 1. Which cloud provider offers the broadest range of services?
AWS offers the broadest range of services, featuring over 200 fully-featured cloud products ranging from basic compute to specialized quantum computing and satellite ground stations. Its long market presence has allowed it to build the deepest catalog of infrastructure and platform solutions available.

### 2. Which provider best integrates with Microsoft technologies?
Microsoft Azure integrates best with Microsoft technologies due to native compatibility with Active Directory, Windows Server, and Microsoft 365 environments. It allows enterprises to easily extend on-premises Windows-based ecosystems to the cloud using existing software licenses.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?
Google Cloud Platform (GCP) is the strongest in Artificial Intelligence and Kubernetes, as Google originally developed Kubernetes and open-sourced it. Additionally, GCP offers specialized hardware like TPUs alongside Vertex AI, making it an industry leader for advanced AI/ML workloads.

### 4. Which cloud platform would you personally choose and why?
I would personally choose AWS due to its comprehensive documentation, huge market demand, and community support. Having exposure to AWS builds versatile skills that apply widely across startups and enterprise environments alike.
